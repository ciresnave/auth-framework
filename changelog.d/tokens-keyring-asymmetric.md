**A `KeyRing` now signs and verifies ES256 and EdDSA tokens, not only HS256.** `JwsSigning` keys in the store join the ring: verification uses the public JWK, signing uses the exported PKCS8, and the newest `Active` key of any supported kind signs, with `Retiring` keys verifying through a rotation. A key verifies only its own algorithm, so a token cannot present a different `alg` for a key id. Other algorithms (RS256, ES384) are skipped and never verify. Nothing changes for a ring holding only HMAC keys. Evidence: three new `tokens::keyring` tests, shown red by mutating the validation algorithm to HS256.
