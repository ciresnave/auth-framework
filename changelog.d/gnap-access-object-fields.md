**Breaking: `GnapAccessRequest` gains `datatypes: Vec<String>`, `identifier: Option<String>` and `privileges: Vec<String>` (RFC 9635 8.2).** The service now carries these three fields of an access object from the request to the access policy instead of dropping them, and writes them back out when a request is rebuilt from rights. Migration: struct literals of `GnapAccessRequest` add `..Default::default()` (the struct now derives `Default`); a policy that granted by type, actions and locations alone is unchanged, but may now see a request that asks for a narrower or wider datatype, identifier or privilege and must decide it. Evidence: `requested_rights_carries_datatypes_identifier_privileges` in `gnap.rs`.
