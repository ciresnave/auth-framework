**Breaking: `GnapTransactionRequest.access_token` takes the RFC 9635 shape.** The field is now `Option<GnapAccessTokenRequests>` (`{"access": [...], "label", "flags"}`, or an array of those) instead of `Option<Vec<GnapAccessRequest>>`, so a request in the RFC's own form parses (ROADMAP G5, slice 1). Build it from grant-level rights with `rights.into()`; the request builder is unchanged; `GnapAccessPolicy::grant` keeps its signature. `GnapService::requested_rights` refuses an empty token request, an empty access type, any flag (`invalid_flag`) and more than one token per request, before anything is stored or issued.
