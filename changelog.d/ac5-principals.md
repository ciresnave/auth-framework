**`access_control::principal`: human, program and agent principals (ROADMAP AC5).** `PrincipalRegistry` holds principals with a stable id (never reused, retired ids stay reserved; empty, whitespace or `*` ids refused), an owner (a human has none; a program or agent needs an effectively active owner, so every principal traces to a human via `root_human`), bound key thumbprints (a thumbprint is bound once for ever and `principal_for_thumbprint` resolves only while the key and the whole owner chain are live) and a lifecycle (active, suspended, retired; suspending an owner deactivates what it owns, retiring it retires everything it owns and revokes their keys). `InMemoryEngine::with_principals` attaches a registry: an unknown, suspended or retired principal (or one under such an owner) is denied with `DenyReason::PrincipalInactive`, and that answer is sensitive so it is never cached. Without a registry any id is accepted, as before. `add_key` refuses an empty thumbprint with the new `PrincipalError::InvalidThumbprint`; `PrincipalRegistry` gains `principals()`, `len()` and `is_empty()`; a lifecycle change made through `principals_mut` is seen by the cache at once (the engine generation moves), so no `invalidate` is needed.
