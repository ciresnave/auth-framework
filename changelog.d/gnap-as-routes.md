GNAP authorization-server HTTP routes (G7, RFC 9635): `GnapAsHttp` (`src/protocols/gnap_as_http.rs`) routes the grant endpoint (`POST` a transaction, `OPTIONS` answers the section 9.2 discovery document) and the token management endpoint (`POST` rotates, `DELETE` revokes, token in `Authorization: GNAP`), with axum (`gnap_as_router`) and actix (`gnap_as_configure`) adapters. Proofs are checked against the URL the deployer configures, never the request `Host`; a missing, wrong-key, wrong-URL or replayed proof is refused with 401 and the token survives. The continuation route is not included yet (the continue URI does not name the transaction). No new dependencies.
