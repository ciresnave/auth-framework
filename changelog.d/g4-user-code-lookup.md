`GnapService::transaction_for_user_code(typed, caller)` finds the pending transaction a person's typed user code belongs to (RFC 9635 3.3.3, G4 slice 3): case- and hyphen-insensitive, constant-time, one refusal for a wrong, malformed, expired or already-decided code, and five wrong codes in five minutes lock that caller out (the right code too).
