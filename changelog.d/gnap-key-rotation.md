GNAP key rotation (RFC 9635 6.1.1): a token bound under `jws` or `jwsd` can be re-bound to a new key by a POST to its manage URI that both keys prove (`GnapService::rotate_token_key_with_proof`, `gnap_jws::verify_attached_rotation` and `verify_detached_rotation`); refusals answer `invalid_rotation` or `key_rotation_not_supported`, other tokens cannot rotate their key, and discovery now reports `key_rotation_supported: true`. A service message that starts with a registered GNAP error code and a colon is answered with that code (`GnapError::from_service_message`, `GnapError::http_status`).
