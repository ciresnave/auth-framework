`GnapService::push_interaction` delivers the `push` callback of an approved transaction (RFC 9635 4.2.2, G4 slice 2). The host is resolved at delivery, the push is refused if **any** resolved address is loopback, private, link-local, metadata, shared or documentation range (11.34, no DNS-rebinding window), and the connection goes to the address that was checked, with no redirect followed and a timeout. New module `gnap_push` with `PushResolver`/`PushSender` traits, `SystemPushResolver` and `ReqwestPushSender` defaults and a typed `PushError`. Evidence: nine unit tests and four service tests; five mutations (the any-blocked check, the open-time guard, redirects, the pin, the approved-state check) each fail a test.
