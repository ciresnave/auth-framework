**Debug redacts secret fields.** `{:?}` of eleven configuration and credential types now prints `<redacted>` where it used to print a secret; an optional secret keeps its shape (`None` stays `None`). Not a breaking change (`Debug` output is not API), but operators who grep logs for these values will no longer find them: a configuration dumped with `{:?}` shows the endpoint, issuer and other ordinary fields exactly as before. Each type has a test that formats it and asserts the secret is absent (the failure message names the type and never prints the value), written red-first.
